# Provisions

WoW Forever addon: one-button macros and an item bar for your best food, drink, potions, bandages and healthstones.
See [CURSEFORGE.md](CURSEFORGE.md) for the full description and [CHANGELOG.md](CHANGELOG.md) for changes.

## Releasing
1. Update `CHANGELOG.md`.
2. Commit, then tag and push: `git tag v1.6 && git push --tags`
3. GitHub Actions packages the addon and uploads it to CurseForge.

Needs the repository secret `CF_API_KEY`. CurseForge project: https://www.curseforge.com/projects/1738354
